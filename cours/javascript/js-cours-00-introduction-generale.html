1) C'est quoi JavaScript ?
JavaScript est un langage de programmation principalement utilisé pour rendre les pages web interactives.
  • Créé en 1995 par Brendan Eich (Netscape).
  • Standardisé sous le nom ECMAScript (ES) par l'ECMA.
  • Utilisé côté navigateur et aussi côté serveur (Node.js).

3) Quel type de langage ?
  • Langage à typage dynamique (faible) : le type d'une variable peut changer selon la valeur.
  • Multi-paradigme : procédural, orienté objet, fonctionnel.
  • Interprété + compilé JIT : le moteur JS lit le code et optimise/compile à la volée.
let x; typeof x; // "undefined" x = 12; typeof x; // "number" x = "Bonjour"; typeof x; // "string"
4) JavaScript, HTML et CSS : qui fait quoi ?
  • HTML : structure de la page (titres, paragraphes, formulaires...).
  • CSS : présentation (couleurs, tailles, mise en page, animations).
  • JavaScript : comportement (clics, validation, affichage dynamique, appels API).
<h1 id="titre">Bonjour</h1> <script> document.getElementById("titre").textContent = "Bonjour JavaScript"; document.getElementById("titre").style.color = "royalblue"; </script>
5) Le DOM (Document Object Model)
Le DOM représente la page HTML sous forme d'arbre d'objets manipulables par JavaScript.
  • Accéder : `getElementById`, `querySelector`, `querySelectorAll`
  • Modifier : `innerHTML`, `textContent`, `style`, `className`
  • Créer/Supprimer : `createElement`, `appendChild`, `removeChild`
6) JSON, XML et échange de données
  • JSON (JavaScript Object Notation) : format texte léger, très utilisé avec APIs.
  • XML : format plus verbeux, historique, encore utilisé dans certains systèmes.
// JSON: texte -> objet const txt = '{"nom":"Sara","age":20}'; const obj = JSON.parse(txt); // objet -> JSON const txt2 = JSON.stringify(obj);

7) AJAX et communication serveur
AJAX permet d'envoyer/recevoir des données sans recharger toute la page.
  • Ancien objet : `XMLHttpRequest`
  • Approche moderne : `fetch` + `Promise` + `async/await`
  • Souvent utilisé avec JSON
fetch("/api/etudiants") .then(r => r.json()) .then(data => console.log(data)) .catch(err => console.error(err));
8) Environnement d'exécution
  • Navigateur : Chrome (V8), Firefox (SpiderMonkey), Safari (JavaScriptCore).
  • Node.js : JS côté serveur, scripts, outils, backend.
  • Le code peut être débogué via la console DevTools (F12).
9) Résumé rapide pour étudiants
  • JS rend les pages web interactives.
  • Il est dynamique, flexible, et exécuté par un moteur JS.
  • Il manipule HTML/CSS via le DOM.
  • Il échange des données avec serveur via AJAX/fetch, souvent en JSON.
  • Il fonctionne côté client et côté serveur.
Conseil pédagogique : commencer par variables/conditions/boucles, puis fonctions/objets, puis DOM/événements, puis AJAX/JSON.
