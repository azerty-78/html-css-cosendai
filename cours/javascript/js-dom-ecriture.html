🌳 Qu'est-ce que le DOM ?

Quand un navigateur charge une page HTML, il ne lit pas juste du texte : il construit un arbre d'objets en mémoire qui représente chaque balise, chaque attribut, chaque morceau de texte. Cet arbre s'appelle le DOM — Document Object Model.

Le DOM est la passerelle entre votre HTML et JavaScript. Sans le DOM, JS ne pourrait pas toucher à votre page. Avec le DOM, JS peut lire, modifier, ajouter ou supprimer n'importe quel élément en temps réel, sans recharger la page.

Imaginez votre HTML comme un plan architectural et le DOM comme le bâtiment réel construit d'après ce plan. JavaScript est l'électricien qui peut modifier les circuits du bâtiment à la volée.

L'objet document est le point d'entrée : il représente toute la page. document.body est le corps, document.head est l'en-tête, etc. Chaque élément HTML devient un nœud (node) dans cet arbre.

📄 document ← racine absolue └─ <html> ← nœud élément ├─ <head> │ └─ <title> │ └─ "Ma Page" ← nœud texte └─ <body> ├─ <h1 id="titre"> ← attribut = propriété du nœud │ └─ "Bonjour !" ├─ <p class="para"> │ └─ "Un paragraphe…" └─ <div id="zone"> └─ <button> "Cliquer" </button>

3 types de nœuds importants :
🔷 Nœud élément → chaque balise HTML (<div>, <p>, <h1>…)
🔶 Nœud texte → le contenu textuel à l'intérieur des balises
🔸 Nœud attribut → id, class, href… (accessibles via .getAttribute())

document.write() 01

Écrit du texte ou du HTML directement dans la page pendant son chargement. ⚠ Si appelé APRÈS le chargement, il efface toute la page ! Rarement utilisé en production.

// Pendant le chargement : document.write("Bonjour tout le monde !"); document.write("<h2>Un titre en HTML</h2>");

.innerHTML = "..." 02

Lit ou remplace le contenu HTML complet d'un élément (balises incluses). C'est la méthode la plus utilisée pour modifier du contenu dynamiquement.

let el = document.getElementById("zone"); el.innerHTML = "<b>Texte <em>enrichi</em></b>"; // += pour ajouter sans effacer : el.innerHTML += "<br>Ligne ajoutée";
// APERÇU RENDU
En attente…
.textContent = "..." 03

Lit ou modifie seulement le texte, sans interpréter le HTML. Les balises HTML sont affichées comme du texte brut — plus sûr contre les injections XSS.

let el = document.getElementById("titre"); el.textContent = "Nouveau titre !"; // Les balises HTML sont affichées telles quelles : el.textContent = "<b>pas rendu</b>"; // affiche le texte
// textContent vs innerHTML
En attente…
.innerText = "..." 04

Similaire à textContent mais tient compte du style CSS (éléments cachés ignorés). Respecte les sauts de ligne visuels. Légèrement plus lent que textContent.

let el = document.getElementById("para"); el.innerText = "Ligne 1\nLigne 2"; // \n crée un vrai retour à la ligne visible console.log(el.innerText); // lecture aussi possible
// APERÇU
En attente…
createElement() + appendChild() 05

Crée un nouvel élément HTML puis l'insère comme dernier enfant d'un parent. C'est la façon "propre" de construire des éléments dynamiquement.

let li = document.createElement("li"); li.textContent = "Nouveau item"; li.style.color = "green"; document.getElementById("liste").appendChild(li);
// ÉLÉMENTS CRÉÉS
    insertBefore() 06

    Insère un élément juste avant un nœud de référence existant. Syntaxe : parent.insertBefore(nouveauNoeud, noeudDeReference).

    let newEl = document.createElement("p"); newEl.textContent = "Inséré AVANT"; let ref = document.getElementById("reference"); ref.parentNode.insertBefore(newEl, ref);
    // LISTE
    insertAdjacentHTML() 07

    Insère du HTML à une position précise par rapport à un élément : beforebegin, afterbegin, beforeend, afterend.

    el.insertAdjacentHTML('beforebegin', '<p>Avant</p>'); el.insertAdjacentHTML('afterbegin', '<p>Début</p>'); el.insertAdjacentHTML('beforeend', '<p>Fin</p>'); el.insertAdjacentHTML('afterend', '<p>Après</p>');
    // RÉSULTAT
    createTextNode() 08

    Crée un nœud texte pur (sans balise). Plus sûr que innerHTML car les caractères spéciaux ne sont jamais interprétés comme HTML.

    let p = document.createElement("p"); let txt = document.createTextNode("Texte sûr <script>"); p.appendChild(txt); // <script> non exécuté !
    // Le HTML dangereux est neutralisé
    En attente…

    getElementsByTagName() 11

    Retourne tous les éléments d'un type de balise donné. Utile pour cibler tous les <p>, <li>, <img>… de la page ou d'une zone.

    let paras = document.getElementsByTagName("p"); console.log("Nombre de <p> :", paras.length); paras[0].style.background = "yellow";
    // RÉSULTAT

    querySelector() 12

    Retourne le premier élément correspondant à un sélecteur CSS. Très puissant : accepte n'importe quel sélecteur CSS (#id, .classe, div > p…).

    document.querySelector("p"); // 1er <p> document.querySelector("#monId"); // par id document.querySelector(".maClasse"); // par classe document.querySelector("div > p.info"); // CSS avancé
    // RÉSULTAT (1er trouvé)
    En attente…
    querySelectorAll() 13

    Retourne une NodeList de TOUS les éléments correspondant au sélecteur CSS. Contrairement à HTMLCollection, NodeList supporte .forEach() directement.

    let tous = document.querySelectorAll("p.info"); tous.forEach(el => { el.style.border = "1px solid cyan"; console.log(el.textContent); });
    // TOUS LES RÉSULTATS
    En attente…
    parentNode · children · nextElementSibling 14

    Navigation dans l'arbre DOM : remonter vers le parent, accéder aux enfants ou aux frères/sœurs d'un nœud.

    el.parentNode // nœud parent el.children // enfants éléments el.firstElementChild // 1er enfant el.lastElementChild // dernier enfant el.nextElementSibling // frère suivant el.previousElementSibling // frère préc.
    // NAVIGATION DOM

    Modifie le style CSS inline d'un élément. Les propriétés CSS multi-mots s'écrivent en camelCase : background-color → backgroundColor.

    el.style.color = "red"; el.style.backgroundColor = "#f0f0f0"; el.style.fontSize = "24px"; el.style.display = "none"; // cacher
