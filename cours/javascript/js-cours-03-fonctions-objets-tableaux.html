01 — Fonctions JavaScript
Une fonction permet de réutiliser du code. Elle peut recevoir des paramètres et renvoyer un résultat avec return.
function addition(a, b) { return a + b; } function bulletin(nom, note = 10) { return nom + " a la note " + note + "/20"; } function afficherElements() { return Array.from(arguments).join(" | "); }

02 — Objets et mot-clé this
Un objet regroupe des propriétés (données) et des méthodes (fonctions). Dans une méthode, this pointe vers l'objet courant.

03 — Tableaux avancés
