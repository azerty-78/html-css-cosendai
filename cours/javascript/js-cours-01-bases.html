Les Variables — Déclaration & Règles de nommage

Une variable est une boîte qui stocke une valeur. En JavaScript, on déclare une variable avec var, let ou const. Les noms doivent commencer par une lettre, $ ou _, sont sensibles à la casse (age ≠ Age), et les mots réservés (if, for, function…) sont interdits.
var prenom = "Amina"; // déclaration classique (portée globale) let age = 22; // portée de bloc (recommandé) const PI = 3.14159; // constante — ne peut pas changer // Noms valides : let maVariable, _temp, $prix; // Noms invalides : // let 1valeur, let for, let ma-variable ← ERREUR

Les Tableaux — Arrays

Un tableau est une liste ordonnée de valeurs. En JS, on l'écrit avec des crochets [ ]. Les indices commencent à 0. Un tableau peut contenir des nombres, des chaînes, même d'autres tableaux (tableau multidimensionnel). La propriété .length donne la taille du tableau.
let voitures = ['BMW', 'Ford', 'Toyota']; console.log(voitures[0]); // → 'BMW' console.log(voitures.length); // → 3 // Tableau 2D (matrice) let matrice = [[1,2,3],[4,5,6],[7,8,9]]; alert(matrice[1][2]); // → 6

Les Opérateurs — Arithmétique, Comparaison, Logique

JavaScript dispose de 4 familles d'opérateurs : arithmétiques (+, -, *, /, %, ++, --), d'affectation (=, +=, -=…), de comparaison (==, ===, !=, >, <…) et logiques (&&, ||, !). L'opérateur === vérifie AUSSI le type, contrairement à ==.

Le Typage Dynamique — typeof et conversions

JavaScript est à typage faible (dynamique) : le type d'une variable change en fonction de la valeur qu'on lui donne. On utilise typeof pour connaître le type actuel. Les conversions explicites se font avec parseInt(), parseFloat(), String(), Boolean()…
let x; typeof x; // "undefined" x = 42; typeof x; // "number" x = "Bonjour"; typeof x; // "string" x = true; typeof x; // "boolean"

La Console — Votre meilleure amie pour déboguer

La console (touche F12 → onglet "Console") est l'outil de débogage numéro 1 en JavaScript. Elle affiche les messages, les erreurs, et vous permet d'inspecter les valeurs pendant l'exécution. console.log() affiche une info, console.warn() affiche un avertissement, console.error() une erreur.
console.log("Bonjour !"); // Message normal (bleu) console.warn("Attention !"); // Avertissement (orange) console.error("Erreur !"); // Erreur (rouge) console.table(['a','b','c']); // Tableau formaté
